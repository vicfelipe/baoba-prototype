# Baobá — protótipo

Protótipo web 2.5D (Three.js + Vite). O jogo fica em [web/](web/README.md); o design e as decisões, em [docs/](docs/README.md); scripts de teste e pipeline, em [tools/](tools/).

- **Jogar localmente:** `cd web && npm install && npm run dev`
- **Build:** `cd web && npm run build` → `web/dist/index.html` (arquivo único)
- **Deploy (Vercel):** configurado em `vercel.json` na raiz.
